[README](../../README.md) · [기획서](../01-planning/PLAN.md) · **요구사항** · [구현 매핑](./TRACEABILITY.md) · [RAG 설계](../03-design/RAG_PIPELINE.md) · [데이터](../04-data/DATA_SOURCES.md)

**기준:** AI 코어 프로젝트 2회차 요구사항정의서 · **우선순위:** MoSCoW (🔴Must 🟠Should 🟡Could ⚪Won't)

## 1. 범위
- **포함:** 품목 검색·선택, 수리/재사용/배출 RAG 답변, 조건 탐색, 국가 환경 브리핑, 비회원 세션.
- **제외(Won't):** 결제·중고거래·시세/수리비 확정·사진만으로 상태 판정·전 세계 배출 규칙 보장.
- **사용자:** 비회원(모든 기능), 운영자(색인·출처 관리).
- **용어:** RAG 1 = 품목 메타데이터(`item_meta`), RAG 2 = 외부 문서(`evidence_docs`).

## 6. 유스케이스 UC-01
1. 비회원이 종이에 `무선 이어폰 / 한쪽 불량 / 대한민국 / 모든 가능성`을 적는다.
2. 종이를 구겨 쓰레기통에 넣고 **"네, 찾아주세요!"**를 누른다.
3. P1 검색어 → 캐시 확인·후보 수집 → P2 선별 → 청킹·색인.
4. `retrieve`: 품목 메타 + 관련 청크 병합 → `generate`: 근거만으로 답변.
5. 구름을 열어 결과·`[근거 n]` 원문 확인 → 후속 질문.

**대안 흐름:** 색인 없음·키 누락·근거 0건·외부 API 실패 → 안내 + 재시도, 수치는 만들지 않는다.

## 7. 제약·가정
- Python 3.10+, Streamlit, ChromaDB, LangChain/LangGraph (과제 지정). 3D는 Next.js + Three.js.
- LLM은 OpenAI 호환 API(SSAFY GMS 가능). 키가 없으면 **오프라인 모드**(규칙 기반, 화면에 표시).
- 공개된 웹 자료라도 대량 수집 허가는 별도. 이용조건이 확인된 출처만 색인한다.
