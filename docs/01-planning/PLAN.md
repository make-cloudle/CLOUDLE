> **Explore the Earth. Uncover the Truth.** 지구에서 문제를 발견하고 → 자료를 모아 → 구름(RAG)으로 분석하고 → 새로운 사실을 발견하는 서비스.

## 1. 왜 만드나
| 항목 | 내용 |
|---|---|
| 문제 | 수리·안전·배출 규칙이 여러 기관과 매뉴얼에 흩어져 있어 찾기 어렵다. |
| 사용자 | 가입 없이 물건을 처리하려는 일반인, 중고 판매·구매자 |
| 해결 | 물건·지역·목적을 고르면 **출처 있는** 선택지와 다음 행동을 알려준다. |
| 차별점 | 프롬프트 대신 **종이 구기기** 입력, **구름을 여는** 결과, 지구 환경 데이터 연결 |

## 2. 다섯 기능이 하나로 이어지는 방식
`Earth SOS(문제 발견) → Cloud Lab(증거를 넣고 분석) · 구름 광장(사람들과 나누고 메모로 정리) → Planet VS(비교로 맥락 이해) → Discovery Book(사실 기록)`
모든 기능이 같은 지구 데이터와 같은 RAG 결과를 다른 방식으로 쓴다. 출석·일반 미션·레벨업은 환경 이해와 관련이 없어 넣지 않았다.

## 2-1. 핵심 흐름 (Cloud Lab)
`지구본 국가 선택 → 구름 브리핑 → 종이에 물건 적기 → 구겨서 쓰레기통 → "찾아볼까요?" → RAG 분석 → 구름 열기 → 후속 질문`

## 3. 우선순위 — MoSCoW × 가치/노력
**MoSCoW**로 범위를 자르고, 같은 등급 안에서는 **가치↑ 노력↓** 순으로 만든다.

| 등급 | 기능 | 가치 | 노력 |
|---|---|---|---|
| 🔴 **Must** | 과제 필수 F2001~F2012 (RAG·근거·조건 탐색·Streamlit) | 높음 | 중간 |
| 🔴 **Must** | 비회원 사용·요청 제한 | 높음 | 낮음 |
| 🟠 **Should** | 3D 지구본·국가 브리핑, 종이 구기기·투입, 구름 열기 | 높음 | 높음 |
| 🟠 **Should** | 사진·파일·카메라 입력, 다국어·다크모드 | 중간 | 낮음 |
| 🟡 **Could** | 수리·수거업체 연결, MMR 비교 | 중간 | 중간 |
| ⚪ **Won't** | 결제·중고거래·시세 확정·로그인 필수화 | — | — |

## 4. 비즈니스 가설
- **B2C 무료:** 비회원 검색·근거 조회로 사용자 확보 (개인정보 미보관).
- **B2B 확장:** 중고·리퍼 업체용 분석 API, 기관(학교·기업) 맞춤 배출 RAG. *제휴·매출은 미확정이며 인터페이스만 설계.*
- **지표:** 분석 완료율, 근거 클릭률, 응답 시간, 조건 검색 정확도.
