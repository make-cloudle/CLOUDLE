## 1. 도메인 선정

| 항목 | 결정 |
|---|---|
| 서비스명 | **CLOUDLE(클라우들)** — Cloud + Cuddle, 확정 서비스명 |
| 도메인 | **순환경제 중 생활용품의 재사용·수리·분리배출 안내** |
| 사용자 | 별도 가입 없이 생활물품을 처리하려는 일반인, 중고 구매자·판매자 |
| 문제 | 수리 가능 여부·제품 안전·배출 규칙이 여러 기관/매뉴얼에 흩어져 있어 찾기 어렵다. |
| 제안 가치 | 물건과 지역·목적을 고르면 근거 있는 선택지와 행동 방법을 제시한다. |
| 차별화 | 프롬프트를 쓰지 않는 드래그 입력, 출처 번호를 확인하는 구름 결과, 환경 데이터와 실천의 연결 |

### PDF 과제의 도메인 3조건

1. **항목 메타데이터 약 100건 이상:** 생활용품 **100~120개 품목을 목표**로 구성. 후보 출처인 [분리의 정석 품목사전](https://www.wasteguide.or.kr/front/dischargeMethod/dictionary.do)은 검색 화면에 **770개 품목**을 표시한다(2026-10-21 열람). *원문 확보·수집 권한·최종 색인 건수는 미검증; 실제 수집 완료로 간주하지 않는다.*
2. **항목별 외부 문서:** 동일 품목을 설명하는 배출 지침, 공개 Q&A, 허용된 제품 설명서 및 리콜자료를 연결. 출처·URL·작성/갱신일·수집일·이용조건 기록. 허가 없이 문서 전문을 대량 복제하지 않는다.
3. **근거가 필요한 질문:** “배터리 내장 이어폰은 일반쓰레기로 버려도 되나?”, “중고 보조배터리 구매 전에 어떤 안전정보를 확인해야 하나?”, “서울에서 고장 난 소형가전을 어디에 배출하나?” — 일반 지식만으로 단정하지 않고 자료와 지역 조건으로 판단해야 함.

**1일 차 16시 게이트:** 100건의 실제 로드·외부 자료 연결·이용조건이 확인되어야 도메인 확정. 미충족 시 과제 지정 **영화 도메인 팩**으로 전환한다(과제 PDF 의무).

**구분:** 실시간·과거 수치는 API/구조화 데이터로 직접 표시하며, **RAG는 품목별 지침·매뉴얼·정책 해설의 검색과 근거 제시**에 사용한다. 폐기물 발생 통계를 실시간 수치처럼 표현하지 않는다.

## 3. 핵심 사용자 흐름

`비회원 방문 → 회전하는 지구본에서 국가 선택 → 오른쪽 구름의 환경 말풍선 → 물건 검색/선택 → 카드 속에 지역·물건·목적 저장 → 카드를 구겨 분석통에 드래그 → 구름의 실제 검색 상태 → 구름을 열어 근거·원문 확인 → 후속 질문`

- **RAG 특화 기능:** `물건의 다음 선택` — 선택한 물건에 대해 가능한 처리 방법, 지역별 배출 조건, 안전·리콜 확인사항을 **출처별로** 안내.
- **조건 탐색:** “서울에서 버리는 배터리 내장 소형가전” 등의 자연어 조건으로 품목 카드 필터링.
- **기대하지 않는 기능:** 이미지 1장으로 실제 수리가격·중고시세·거래 진위·물건 상태를 확정하지 않는다.

## 4. 우선순위 산정(가볍게 2가지)

- **MoSCoW:** 과제 의무 및 답변 신뢰성은 Must, 차별화 UI·추가 데이터는 Should, 효과음·코스튬은 Could, 거래·결제는 Won't(이번 범위 제외).
- **가치 × 노력:** 낮은 노력/높은 가치부터. *아래 평가는 팀 내부 가정이며 사용자 검증 전 가설이다.*

| 기능 | 가치 | 노력 | 판단 |
|---|---|---|---|
| 품목 선택·근거 답변·인용 | 높음 | 중간 | 최우선(Must) |
| 비회원 사용·조건 검색 | 높음 | 낮음 | 빠른 구현(Must) |
| 세계 폐기물 통계 연동 | 중간 | 낮음~중간 | 지구본 데이터(Should) |
| 드래그·구름 결과 연출 | 높음 | 중간~높음 | 차별화(Should) |
| 풀 3D 캐릭터 커스터마이징 | 중간 | 높음 | 후순위(Could) |

## 5. 비즈니스 가설·성과지표

- **무료 B2C:** 비회원 기본 검색과 근거 조회로 사용자 확보. 개인 데이터는 세션 종료 후 보존하지 않는 방향.
- **B2B:** 리퍼비시·중고 업체 대상 문서 기반 안전/검수 FAQ API, 수리·수거업체 연결 수수료(제휴 시) 검토. *제휴·매출 발생은 미확정.*
- **검증 지표:** 분석 완료율, 근거 클릭률, 질문당 평균 처리시간, 조건 검색 정확도, 업체 연결 버튼 클릭률. 초기 측정값은 개발 후 수집.

## 6. 3일 개발 계획·위험

| 시점 | 핵심 산출물 |
|---|---|
| 1일 차 16시 이전 | 도메인 100건·권리 확인, RAG 1 항목 텍스트·1차 색인 |
| 1~2일 차 | 프롬프트 3개, RAG 2 문서 수집·청킹·색인, LangGraph 2노드, 근거 번호 |
| 2~3일 차 | 비회원 UI·조건 탐색·진행 상태, 도메인 특화 기능, 선택 심화 |
| 3일 차 | 검증 캡처·요구사항 대조·셀프/상호 점검·제출 |

**주요 위험:** 원문 재이용 허가 미확인 / 서울 외 배출 규칙 공백 / 외부 API 키 발급 지연 / 3D 개발 과투입 / LLM 출처 환각. 대응은 **데이터 확보 게이트 → 허용된 문서 사용 → 범위 제한 → 필수 RAG 우선 → 근거 없으면 판단 보류**이다.
