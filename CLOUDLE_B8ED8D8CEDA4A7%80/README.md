**Cloud + Cuddle** · **비회원 RAG 자원순환 서비스**  
버릴까 고민되는 물건의 **수리·재사용·분리배출** 방법을 실제 문서에서 찾아 근거와 함께 안내합니다.

## 🌍 사용자 경험
1. **3D 지구본** 회전·국가 선택 → 구름 캐릭터가 환경 브리핑(대기질 관측시각·폐기물 통계연도 표시).
2. **물건 + 지역 + 목적** 카드를 구겨 분석통에 드래그 → AI 검색 진행.
3. **구름을 열어** 방법·주의사항·출처 확인 → 후속 질문.

## 🧠 RAG 설계
- **RAG 1:** 품목 메타데이터 **100건 이상** → `item_meta` 색인.
- **RAG 2:** 외부 배출 지침·안전 문서 수집/청킹 → `evidence_docs` 색인.
- **프롬프트 3개:** 검색어 추출 → 문서 후보 선별 → 근거 답변.
- **LangGraph:** `retrieve → generate`; 두 색인 병합·중복 제거·근거 번호/원문 링크. **근거 없으면 확인 불가.**
- **환경 수치:** API·통계 직접 조회, **RAG는 관련 문서 해설** 담당.

## 📌 프로젝트 기준
- **과제 필수:** `F2001~F2012`, `NF2001~NF2007` / **심화:** `F2013~F2016` 선택.
- **우선순위:** MoSCoW + 가치/노력; RAG 완성 → 비회원 UX → 3D 연출.
- **1일 차 16시:** 100건·외부 문서·이용조건 확보 확인(미달 시 지정 영화 팩).
- **검증:** 색인 중복·조건 검색·인용 일치·근거 부족/오류 처리.

## 🔧 기술·확장
Python · LangGraph · ChromaDB · Streamlit; 3D UI는 Three.js 검토.  
자료 후보: 품목사전·공공데이터·제품안전정보·World Bank (**이용조건 검증 전**).  
**수익화 가설:** 무료 비회원 서비스 + 수리·중고업체 연결/B2B RAG API.
